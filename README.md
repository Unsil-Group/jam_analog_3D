![OpenGL 3D Simulation](https://img.shields.io/badge/OpenGL-3D%20Simulation-5586AC?logo=opengl)
![Python Powered](https://img.shields.io/badge/Python-Powered-3776AB?logo=python)

**Experience a stunning 3D clock monument in an urban landscape!** Perfect for architecture visualization, education, and digital art projects.

## 🌟 Key Features

| Feature                | Description                                   |
| ---------------------- | --------------------------------------------- |
| 🕰️ **Real-Time Clock** | Smoothly animated hour/minute/second hands    |
| 🏗️ **3D Environment**  | Minimalist cityscape with buildings and roads |
| 🎮 **Full Controls**   | WASD movement + mouse look + **zoom in/out**  |
| 🔄 **360° View**       | Rotate camera any direction                   |
| ⚡ **Light Effects**   | Basic lighting for realism                    |

## 🚀 Quick Start

1. **Install requirements**:

   ```bash
   pip install PyOpenGL PyOpenGL_accelerate pygame
   ```

2. **Run the simulation**:

   ```bash
   python main.py
   ```

3. **Explore!**:
   - `WASD` to move
   - `Mouse` to look around
   - `Scroll` to zoom
   - `ESC` to exit
